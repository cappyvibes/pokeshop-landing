# Pokeshop Landing

Modern Pokémon TCG landing page built with Next.js, TypeScript and TailwindCSS.

## 🚀 Live Demo
https://pokeshop-landing.vercel.app/

## ✨ Features
- Modern responsive UI
- Mobile-first design
- Fast performance
- Smooth animations
- SEO-friendly structure
- Pokémon TCG themed branding

## 🛠️ Tech Stack
- Next.js
- React
- TypeScript
- TailwindCSS

## 📦 Installation

```bash
git clone https://github.com/cappyvibes/pokeshop-landing.git
cd pokeshop-landing
npm install
npm run dev
```

## 🎯 About The Project

This project was created as a modern landing page concept for a Pokémon TCG store.
The main goal was to practice building clean UI, responsive layouts and production-style frontend architecture using modern web technologies.
